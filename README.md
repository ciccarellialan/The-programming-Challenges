# The Programming Challenges

This repository contains my solutions to programming problems from the book *The Programming Challenges*.

## Purpose

The main purpose of this project is to strengthen my programming fundamentals through problem solving.

The problems cover different situations and levels of complexity, requiring me to understand the problem, choose an appropriate approach, and implement a solution in C++.

I also use this project to practice writing readable and maintainable code by applying Clean Code principles, such as descriptive variable names and clear code structure.

## Language

* C++

## Repository Structure

Each problem has its own source file and is named after the corresponding problem.

## Current Progress

This is an ongoing project. New problems will be added as I continue working through the book.
